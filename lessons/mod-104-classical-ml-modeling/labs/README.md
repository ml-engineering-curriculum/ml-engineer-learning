# Labs for mod-104-classical-ml-modeling (Classical ML Modeling: Regression, Trees, Ensembles)

Each lab is a short guided drill (30–45 minutes) on a single chapter's
load-bearing idea. The labs do not duplicate the module's four
exercises — they are the smaller, faster warm-ups that build the
reflexes the exercises then assume.

| # | Lab | Companion chapter | Duration |
|---|---|---|---|
| 01 | [`KFold` vs `GroupKFold` optimism gap](lab-01-groupkfold-optimism-gap.md) | 07 — Cross-validation strategies | ~30–45 min |
| 02 | [Why regularised linear models need a `StandardScaler`](lab-02-scaling-and-ridge.md) | 02, 03 — Linear models and regularisation | ~30–45 min |
| 03 | [Random vs grid search on the same budget](lab-03-random-vs-grid-same-budget.md) | 08 — Hyperparameter search | ~30–45 min |

Do the labs in any order. Each is self-contained and lands you in a
single Python file you can run end-to-end.
